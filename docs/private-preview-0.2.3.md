## 알아두어야 할 것

### 키는 직접 넣습니다 (BYOK)

개발자 공용 키가 들어 있지 않습니다. 전사와 AI 추출을 쓰려면 본인 OpenAI 키가 필요하고, **회의
제목과 회의록 본문이 OpenAI로 전송됩니다.** 같은 프로젝트에서 이미 승인한 결정·업무·미해결
질문의 본문도 함께 전송됩니다 — 모델이 "이번 회의가 그중 무엇을 바꿨는지" 판단해야 하기
때문입니다. 프로젝트·회의·참석자 식별자와 로컬 프로필은 전송되지 않습니다.

요청은 `store: false`로 보내므로 응답이 나중에 조회되도록 저장되지 않습니다.

### 분석이 실패한 회의는 다시 분석할 수 있습니다

회의는 먼저 저장되고, AI 분석은 그 뒤에 별도로 돌아갑니다. 그래서 분석만 실패하는 일이 있습니다 —
키체인 확인 창에 응답하지 않았거나, 요청이 제한됐거나, 서버가 응답하지 않았거나, 연결이 끊긴
경우입니다. **회의와 회의록은 그대로 남습니다.**

이럴 때 회의 화면 제목 옆에 `AI 분석 다시 시도`가 나타납니다. 저장된 그 회의를 그대로 다시
분석하므로 **회의록을 다시 붙여넣을 필요가 없고, 회의가 하나 더 생기지도 않습니다.** 앱을 껐다
켜도 그 회의를 열면 버튼은 그대로 있습니다.

결과가 하나라도 나온 회의에는 이 버튼이 나타나지 않습니다. 이미 나온 제안을 다시 검토하거나
승인한 결과를 다시 분석하는 것은 이 기능이 하는 일이 아닙니다.

**스스로 다시 시도하지 않습니다.** 재시도는 누를 때만 일어나고, 실행 중에는 버튼이 비활성화되며,
두 번 눌러도 요청은 한 번만 나갑니다.

### 한 번의 추출이 최대 3번 요청할 수 있습니다

응답이 429(요청 제한)나 5xx(서버 오류)면 같은 요청을 최대 2번까지 다시 보냅니다. 즉 **추출 1회당
HTTP 요청은 최대 3회**입니다. 사용료는 본인 계정에 청구되므로 이 상한을 알고 계셔야 합니다.
타임아웃과 네트워크 실패는 재시도하지 않고 바로 오류로 끝납니다.

### 새 빌드를 설치하면 키체인 확인 창이 뜰 수 있습니다

ad-hoc 서명은 빌드마다 값이 달라집니다. macOS는 저장된 키를 "이전 빌드가 저장한 것"으로 보기
때문에, 새 빌드에서 처음 추출할 때 **로그인 키체인 암호를 묻는 창**이 뜰 수 있습니다.

이 창을 무시해도 앱이 멈추지는 않습니다. 몇 초 안에 "결과 0건"과 안내 문구로 끝나고, 저장한
회의는 그대로 남습니다. AI 설정을 한 번 열어 창에 응답한 뒤, 그 회의에서 `AI 분석 다시 시도`를
누르면 됩니다. `항상 허용`을 누르면 그 빌드에서는 다시 묻지 않습니다.

### 데이터는 이 Mac에만 저장됩니다

```
~/Library/Application Support/com.haena.HAENA/
```

프로젝트·회의·전사·프로필·알림·Agent 기록·연속성 사이드카가 모두 이 폴더의 JSON 파일입니다.
서버로 동기화되지 않습니다. **앱을 지워도 이 폴더는 남으므로**, 데이터까지 지우려면 폴더를 직접
삭제하세요. 가져온 오디오는 같은 폴더의 `Audio/` 아래에 있습니다.

### 샘플 데이터 생성 기능이 빠졌습니다

이전 빌드의 `알림 검증 샘플 만들기` 버튼은 이 릴리스에 **없습니다.** 고정 식별자를 가진 프로젝트·
회의·업무를 실제 저장소에 만드는 기능이라, 개발용 빌드에만 남겼습니다. 이미 그 샘플을 만든 적이
있다면 데이터는 그대로 있고, 새로 만들 수단만 사라집니다.

## 이전 빌드

`0.2.3 (6)`은 이 빌드로 대체된 예비 후보입니다. 저장된 회의를 다시 분석할 방법이 없어, 분석이
한 번 실패하면 같은 회의록을 다시 붙여넣어 **중복 회의를 만드는 것 말고는 복구할 길이 없었습니다.**
배포하지 않았습니다.

## 알려진 제한

- **서명·공증 없음.** 첫 실행에 우클릭 → 열기가 필요합니다.
- **자동 업데이트 없음.** 새 빌드는 직접 받아 교체해야 합니다.
- **회의 삭제와 연속성 기록.** 회의를 지우면 그 회의에서 나온 제안이 일부 남을 수 있습니다.
  정리 로직은 구현 중이며 이 릴리스에는 포함되지 않았습니다.
- **회의록을 고쳐서 다시 분석할 수는 없습니다.** `AI 분석 다시 시도`는 저장된 회의록 그대로
  다시 보냅니다. 이미 결과가 나온 회의를 다시 분석하는 기능도 없습니다.
- **오디오 전사 품질은 미측정.** 마이크 녹음과 전사 자체는 동작하지만 잡음·다화자 환경의 정확도는
  측정하지 않았습니다.
- **한국어 회의 기준.** 다른 언어는 검증하지 않았습니다.
- **Calendar 연동 없음.** 회의 준비는 사용자가 직접 실행합니다.
